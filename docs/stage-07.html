Stage 07 · Visible Building Blocks

VirtualList + List + Pagination + Menu + Picker-family

Stage 07 在已通过的 VirtualList / List / Pagination / Menu 基础上补齐 Picker-family 可复用层：OptionList、Calendar、TimePanel、ColorPanel；Select / DatePicker / TimePicker / ColorPicker 仍留在 Stage 08。

Interaction Contract

Arrow / Home / End / Page → activeKey → .is-active → ensureVisible(nearest)
Enter / Space / Click → activation → List selection/value

真实 DOM focus 停留在稳定的搜索输入框或列表 viewport；动态 item 不使用 roving focus，也不通过 DOM class 反推业务状态。

VirtualList · Standalone

当前状态



数据量：100000。DOM 只保留当前可见范围与 overscan；VirtualList 不理解 selection、activeKey 或 List 业务。







List · Standalone


State

List + VirtualList · Composed


State
10000 行；默认选择 value-9000。方向键移动 activeKey 时已提交 value 保持不变。







Pagination · Standalone


State


Pagination 直接消费 Generic PaginationModel。页码 token、pager budget、单页 gap 展开、ellipsis 隐藏区间与跳转目标都由 Model 推导；Visible Pagination 只负责 DOM、文案、共享 Components.Select page-size control 与 jumper draft 交互。动态页码 DOM 重建仍由稳定 root 的 EventDelegation 接管。








Menu · Standalone + Nested Submenu


State
Menu 已重新定义为导航组件：selectedKey 表示当前导航，activeKey 只表示键盘光标，openKeys 表示展开导航分支。








Picker-family Building Blocks



  
OptionList
直接组合 List；方向键只移动 activeKey，Enter/Click 才改变 value。

  
Calendar
翻月只改变 viewValue；Arrow 只改变 activeKey；Enter/Click 才选择 value。

  
TimePanel
Hour / Minute / Second 由 OptionList 组合，面板自身不包含 popup 或 confirm 事务。

  
ColorPanel
HSV / RGB / Alpha 转换与 presets 属于 panel；弹层、输入框和确认流程留给 Stage 08 ColorPicker。
