## 3. 最终一轮真实浏览器验收额外修复的问题

真实 Chromium 组合矩阵并非只验证已有功能；它又发现并修掉了 Node/static 路径未触达的最后一批问题：

### 3.1 Runtime Schema / composition 参数

修复：

1. 可选 option 值为 `undefined` 时，不应被普通 type rule 误判；
2. Modal/Drawer `duration` 支持真实 API 的 number / pair；
3. Modal/Drawer `autoFocus` 支持 `false | selector | Element | function`；
4. Scroll `attachViewport()` 的 adapter-only `controller` 不再泄漏给 Runtime unknown-option validation。

### 3.2 Canonical dependency adoption

修复：

- FormBridge 已迁入 ValueEquality，但实际 capability binding 漏失导致 `ReferenceError`；现已绑定 canonical ValueEquality。

### 3.3 Destroy / historical generation residue

修复：

- Control destroy 中旧 generation 体系迁移后遗留的 `resetGeneration` 悬空引用已删除。

### 3.4 DOMProjection resource leak

真实组合 Diagnostics 捕获：

```text
DOMProjection.activeProjections +28
DOMProjection.activeEntries       0
```

根因：

- `Item.projectClasses/projectStyles` 在 resolver 为空时仍创建 0-entry lease；
- ItemCollection 丢弃/rebuild DOM subtree 前未统一释放 projection lease。

最终修复：

- 空 class/style projection 不再分配 DOMProjection；
- Item 增加统一 subtree `clearProjections()`；
- ItemCollection 在 subtree rebuild 与 destroy 前释放 projection ownership；
- verify-core 增加静态防回退。

## 7. Deferred / Unsupported：不是遗漏

### Deferred / non-blocking

- Optional ViewState storage adapter：localStorage / sessionStorage / server store。

核心已经提供 `getViewState/applyViewState/resetViewState`；按手册要求不把 storage 强绑到 Table core。

### Explicit Unsupported / current baseline boundary

- Table grouped / complex header；
- automatic responsive details；
- Table private overflow Tooltip/expand owner；
- full Shadow DOM composed-tree contract；
- strict Trusted Types CSP baseline；
- Table multi-sort；
- SearchBuilder/SearchPanes；
- Spreadsheet range/copy/fill；
- heavy CRUD Editor/Form Engine；
- TreeTable 强绑普通 Table。

这些能力如果未来出现真实需求，必须先扩 Feature Matrix / contract，再实现；不得以半支持或第二套 owner 方式加入。
