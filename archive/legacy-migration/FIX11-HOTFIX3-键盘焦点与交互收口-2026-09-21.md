# FIX11 HOTFIX3：键盘焦点与交互收口

日期：2026-09-21
版本：QXFRAME9A7C2 v2.19.81
基线：FIX11 FINAL HOTFIX2

## 本轮收口内容

本轮针对键盘焦点、虚拟焦点、Tab 顺序以及鼠标/键盘值提交问题进行收口，主要包括：

- TreeSelect：Enter 正确提交当前活动项；tree toggle 不再独立进入 Tab 焦点。
- DatePicker：年月 drill 后返回日期网格时保持活动日期；方向键不再跳回旧年月日；双面板日期导航可跨左右面板连续移动；预设模式移除隐藏/不可见 Tab stop；Calendar + TimePanel 焦点可以进入 TimePanel。
- PeriodPanel：去除双层 outline，保持单一虚拟焦点表达。
- TimePanel / WheelPanel：由最外层作为真实键盘焦点 owner，内部列与选项不进入 Tab 顺序，由外层键盘事件维护虚拟焦点。
- Tags：overflow 可进入焦点；tag close 不再单独进入 Tab 顺序；tag shell 承担虚拟焦点，Backspace 删除当前虚拟焦点 tag；Add Tag 按钮本身具备 focus-visible outline。
- InputNumber：恢复 ArrowUp / ArrowDown 键盘增减。
- InputOTP：移除外层重复 outline，仅保留内部当前输入段的键盘焦点表现。
- Rate / Slider：修复演示与交互值更新，使键盘和鼠标均能正确改变值。
- Select：支持 Home / End 跳转至首尾有效选项；clear 按钮不进入 Tab 顺序。
- ColorPicker：Swatch-only 模式保留可进入键盘焦点的真实 focus owner。
- Dropdown：多选子菜单的父项可勾选整支，并与子项 checked / indeterminate 状态同步。
- Tabs：focus-visible outline 作用于 `.qxframe9a7c2-tabs-tab`；tabpanel 不再制造额外 Tab stop。
- Steps：connector 从 `.qxframe9a7c2-steps-item-wrapper` 内移出，避免 item 聚焦 outline 包含连接线。
- Control / Static TextField enhancer：补充键盘焦点投影与 outline。
- 通用 FocusManager：原生可聚焦元素显式 `tabindex="-1"` 时不再被错误重新纳入 tabbable 集合，从根源修复 clear/toggle/hidden control 等多余 Tab stop。
