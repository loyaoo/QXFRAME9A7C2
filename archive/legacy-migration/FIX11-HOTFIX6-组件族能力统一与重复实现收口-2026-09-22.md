# FIX11 HOTFIX6 — 组件族能力统一与重复实现收口

日期：2026-09-22

## 目标

本轮不再按单个组件追加补丁，而是针对前几轮源码审计发现的“同一种能力由多个组件分别维护一套规则/状态机”的问题进行组件族级收口。原则是：组件允许保留业务适配器，但同一种状态、规则、生命周期或键盘/焦点算法只能有一个 canonical owner。

新增 `src/manifests/family-capabilities.json`，固定 25 个已审计组件族能力；`tools/verify-core.js` 会验证 owner、consumer 和关键源码委托关系，防止后续版本重新长出平行实现。

## 25 个已收口组件族能力

1. Overlay Frame：`Headless.OverlayFramePolicy` + `DOMHeadless.OverlayFrameShell` + `OverlayRuntime`；Modal/Drawer 共用按钮 AsyncAction、footer、guarded close、销毁资源链。
2. Picker Session：`Headless.PickerSession`；DatePicker/TimePicker/ColorPicker/WheelPicker 共用 draft/commit/cancel/rollback。
3. Picker Footer：`PickerField.createConfirmFooter`；四类 Picker 共用确认/取消 footer。
4. Field Host：`DOMHeadless.FieldHost`；Select/TreeSelect/Cascader/Autocomplete/PickerFieldBase 共用 rendered/projection/headless DOM 入口。
5. Selected Tags：`Headless.SelectionTags` + `DOMHeadless.TagNavigation`；Select/TreeSelect/Cascader/DatePicker multiple/TagInput 共用 tag 投影与左右虚拟焦点删除。
6. Temporal Grid：`Headless.TemporalGrid`；Calendar/PeriodPanel 共用方向键、Home/End、PageUp/PageDown 网格动作语义。
7. Temporal Date Utils：`Headless.DateUnit`；Calendar/DatePicker 不再各自维护月份/日期基础运算。
8. Hierarchy Model：`Headless.TreeModel` + `Headless.ItemAccessors`。
9. Hierarchical Selection：`Headless.HierarchicalSelection`；Tree/Cascader/Dropdown 直接复用，TreeSelect 通过 Tree 委托；父子 checked/indeterminate/cascade 只有一个规则 owner。
10. Search Pipeline：`Headless.SearchState` + `ItemCollection`；Select/TreeSelect/Tree/Cascader/集合类搜索状态不再自行持有 `searchValue` 状态机。
11. Item Accessors/Schema：`Headless.ItemAccessors` + `Headless.ItemSchema`；key/value/label/disabled/children 与递归校验统一。
12. Responsive Overflow：`DOMHeadless.ResponsiveOverflow`；Tags/Tabs/Menu 共用 Resize/Scheduler 生命周期，并统一 `requiredSize()/fitPrefix()` 的前缀宽度、gap 与尾部 disclosure 占位计算；组件只保留自身 DOM 测量与业务投影。
13. Clear Action：`Headless.ClearAction` + Control；字段族 clear 的 disabled/readOnly/loading 规则统一。
14. Interaction Policy：`Headless.InteractionPolicy`；disabled/readOnly/loading/busy 的可聚焦、可激活、可编辑规则统一。
15. Trigger Consumer：Trigger 为 popup consumer 的唯一触发器状态 owner。
16. Notice Preset：`Headless.NoticePreset` + NoticeService；Message/Notification 共用 stack normalization、notice chrome/icon/progress/close 与 channel 生命周期。
17. Roving Projection：`DOMHeadless.RovingProjection`；Tabs/Steps/Collapse 共用 roving tabindex/active DOM 投影。
18. Native TextField Shell：TextField 作为 Control 的薄适配器，不再维护第二套 native-field 状态机。
19. Option Transaction：`Headless.OptionTransaction`；复杂组件 immutable option 拒绝规则统一。
20. Value Equality：`Headless.ValueEquality`；补充 `copyDeep`，并修复跨 realm plain object/array 深比较，保证 `copyDeep(value)` 与原值深等价但不引用别名。
21. Option Validation：ComponentRuntime OptionSchema + Core.Utils；不再新增组件本地 validator 体系。
22. Size/Density：Core.Utils.normalizeSize/normalizeEnum；组件只允许做 label/fallback 适配。
23. Element Resolution：Core.DOM.requireElement；Trigger/Dropdown/Tooltip/Popover 等不再自己解析 selector。
24. Open State Bridge：`Headless.OpenStateBridge`；popup/picker 的 callback + emitter open-state 分发统一。
25. Listener Lifecycle：Core.DOM.listen + Lifecycle；`src/modules` 内直接 `.addEventListener()` 已清零。

## 本轮额外修复

- `HierarchicalSelection.toggleCascade()` 保留目标节点真实 sibling index，避免自定义 index-sensitive accessor 在级联选择中被错误地按 index 0 计算。
- Modal/Drawer 的相同按钮渲染、AsyncAction pending/error/closeOnClick、关闭重入保护和销毁资源链移入 `OverlayFrameShell`。
- Message/Notification 的 stack 规则移入 `NoticePreset`；公共 notice style/motion/icon/close/progress chrome 移入 NoticeService。
- Select/TreeSelect 的搜索 query 状态迁入 `SearchState`。
- Tree 的 direct child/descendant check 算法迁入 `HierarchicalSelection`。
- TimePicker/ColorPicker 等剩余深值 copy/equality 迁入 `ValueEquality`。
- DatePicker 本地 `addMonths` 删除，统一委托 `DateUnit.addMonths`。
- Tags/Tabs/Menu 原先各自维护的“可见前缀宽度 + gap + overflow disclosure”拟合循环迁入 `ResponsiveOverflow.requiredSize()/fitPrefix()`。
- 浏览器资源平衡基线增加 Scheduler quiescence 等待，避免在基线快照时恰好存在跨 frame layout task 导致 `layoutPendingTasks=-1` 的假性不平衡；最终仍使用严格 `Diagnostics.assertBalanced()` 验证零净泄漏。

## 前几轮交互回归继续保留
